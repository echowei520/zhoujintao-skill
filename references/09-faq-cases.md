# 典型问题案例库（30 例）｜P4 答疑产品化 2026-09-22

> 用法：接到新问题先匹配本库案例，命中则按案例框架作答（口吻走 04-voice checklist）；未命中走 SKILL.md 五步协议。
> 每例结构：**结论先行 → 框架路径（模型编号见 07-mental-models.md）→ 原话锚点（场合+日期）→ 时间立场**。
> 铁律不变：先生原话逐字引用；身后事实/框架外推必须标明；不作投资建议。

## A · 房地产

**A1 现在的房子还能买吗？**
- 结论：先定阶段——萧条期房地产不是首选，本人在世最后口径是"2017-2019 中美共振下行"。
- 路径：⑥主导国标定 → ①嵌套（20 年房地产周期位置）→ ②收口（保值优先）。
- 锚点：《康波中的房地产周期研究》2016-09-05；微路演 2016-12-27"房价先涨后跌，随后触发一定的系统风险"。
- 立场：原话至 2016-12；此后行情为身后事实，只作校准。

**A2 中国房价会像日本一样崩吗？**
- 结论：路径可参照但国别不同——日本 1970s 与 1990s 两种剧本，中国工业化后发、城镇化差异大，倾向"回落但方式渐进"。
- 路径：⑥ → 地产大拐点六部曲的国际经验框架。
- 锚点：地产大拐点（6）2014-07-18"国际经验与中国境况猜想"。
- 立场：框架原话；对 2016 后走势只作事后校准。

**A3 一线城市是不是永远涨？**
- 结论："永远涨"不是周期语言；一线库存下降+开工跟不上短期可拉升，但趋势由周期定。
- 锚点：微路演 2016-12-27（一线房价与汇率组合情景）。
- 立场：原话口径，注明情景推演性质。

**A4 买房和买黄金哪个保值？**
- 结论：萧条期"第一目标是保值"，黄金流动性优于不动产；但地产在回升期是增长核心载体——阶段不同答案不同。
- 路径：模型 5 时点适用条件（萧条确认期黄金上位）。
- 锚点：人生就是一场康波 2016-03-16"资产只能相对保值"。

## B · 黄金

**B1 黄金还能配吗？什么时候买？**
- 结论：看实际利率与美元强势终结时点，不看名义加息；萧条期黄金超越大宗。
- 路径：模型 5 三支柱 + 美元时点。
- 锚点：《康波体系下的黄金价格》2016-08-16；微路演 2016-12-27"配置时点在美元强势终结的时候"。

**B2 加息了黄金是不是完了？**
- 结论：加息≠实际利率上行；名义冲击是短期扰动。
- 路径：模型 5。
- 锚点：《康波体系下的黄金价格》2016-08-16（实际利率框架）。

**B3 现在金价多少合适入手？**
- 结论：拒答点位——框架只给方向与时点性质，不给价格目标（硬性护栏 2）。
- 锚点：输出契约；本人全程只有方向+区间表述的纪律。

## C · 商品

**C1 商品跌了五年，是底吗？**
- 结论：先问级别——康波熊未完、产能周期低点在 2018-2019、超级周期低点 2019，但中间有年度级别涛动反弹。
- 路径：①嵌套（商品四周期）→ ⑦投机触发。
- 锚点：《从超级周期看商品投资机会》2016-01-21。
- 立场：2016 反弹已成身后事实，用其校准涛动节奏。

**C2 需求没起色，商品凭什么涨？**
- 结论：大宗拐点是"效率递减+追赶国+长鞭"的累积释放，不是当期供需。
- 路径：模型 4。
- 锚点：周期之轮系列《价格体系的重塑》2012。

**C3 这个底是政策买出来的吗？**
- 结论：盯中间商行为不盯政策文件——"任何反转点的基本机制就是人的投机行为"。
- 路径：模型 7（投资品→半投资品→消费品传导）。
- 锚点：周期之轮系列；涛动周期录 04《周期的救赎》。

**C4 原油怎么看？**
- 结论：原油跟随美国库存周期节奏，与黑色系时差明显。
- 锚点：微路演 2016-12-27"原油等商品，将能够与美国的库存周期一起继续维持强势到明年上半年"。

## D · 股市

**D1 这是不是新牛市的起点？**
- 结论：先定主导周期级别与顶底性质——顶是系统性问题、底从来不是；萧条期反弹不改方向。
- 路径：① → ⑧ → ③（创新未兑现则无繁荣起点）。
- 锚点：《大拐点、新起点与两个转换》2010-06-18。

**D2 无风险利率下降不就是牛市逻辑吗？**
- 结论：本人明确反驳过——"无风险利率下降牛市论：是个大奇迹！"牛市基因在经济周期不在利率单因子。
- 锚点：牛熊基因研究之三（2014）。
- 立场：原话口径。

**D3 政策底出现了，市场底还远吗？**
- 结论：政策底≠市场底；库存重建机制重启（订单、价格、中间商行为）才是市场底前提。
- 路径：模型 7。
- 锚点：周期之轮（5）2012-02-16"库存加速器：期待破局"。

**D4 7 月数据超预期，经济见底了吗？**
- 结论：单月数据不足为凭，看产出缺口+库存+地产三线共振，"双底"反弹要防间歇性。
- 锚点：周期之轮（24/25）2013-07/08。

**D5 牛市里该满仓周期股吗？**
- 结论：本人纪律第一是保值第二是流动性；行业轮动跟随库存周期（早周期→中游→上游）。
- 锚点：周期之轮系列行业配置逻辑；访谈 2013（纪律表述）。

## E · 美元与汇率

**E1 美元进入长期升值怎么办？**
- 结论：强美元冲击资源国与新兴市场，但本人判断本轮强势弱于前两轮——博弈与协作下的"反抗"空间存在。
- 路径：模型 2 + ⑥。
- 锚点：《宿命与反抗》2015-09-25。

**E2 人民币会大幅贬值吗？**
- 结论：跟随中美库存周期时差判断——中国库存回落而欧美上行时压力最大；不必然趋势性贬值。
- 锚点：微路演 2016-12-27；地产大拐点（6）"人民币不必然贬值"。

## F · 康波与人生

**F1 人生发财靠康波，我的机会在哪年？**
- 结论：一代人有三次房地产周期、九次固定资产投资周期、十八次库存周期；85 后第一次机会 2019 年附近（三低点共振）。
- 锚点：人生就是一场康波 2016-03-16；南开报告 2015-04-15。
- 立场：原话；2019 事后的验证作身后事实陈述。

**F2 现在该持有现金吗？**
- 结论：萧条期"持有现金是对的"，但不躺平——等待反抗窗口（库存反弹）再出手。
- 路径：模型 2（宿命≠躺平）。
- 锚点：人生就是一场康波 2016-03-16。

**F3 工资不涨、阶级固化，普通人还有机会吗？**
- 结论：康波是 60 年的，人生就是其中一段；在萧条期修炼，在回升期收获——机会属于"在正确的时点做正确的事"的人。
- 锚点：人生就是一场康波 2016-03-16"人生就是一场康波"段。

**F4 该跳槽/创业吗？**
- 结论：只给周期视角不给决定——看行业所处库存周期位置与主导产业阶段（萧条期工序创新、孕育新技术）。
- 路径：模型 3 + 护栏 7。
- 锚点：《从熊彼特到罗斯托》理论篇（2）。

**F5 现在是投胎错了吗？**
- 结论：他常说的反问式自嘲——"人生发财靠康波"，埋怨投胎不如读懂周期；幽默化解后照常给定位。
- 锚点：演讲实录口语风格（04-voice 自嘲库）。

## G · 宏观与政策

**G1 强刺激能走出通缩吗？**
- 结论：宽松解决不了全球通缩问题，"应该是货币体系出了问题"；需要复苏但不需要强复苏。
- 锚点：微路演 2016-12-27；周期真实义系列。

**G2 供给侧改革怎么看？**
- 结论：这是"需要复苏但不需要强复苏"约束下的主动反抗——去产能是宿命中的作为。
- 路径：模型 2 政策层。
- 锚点：涛动周期录 06《宿命与反抗》2015 篇章。

**G3 滞胀会来吗？**
- 结论：从衰退向萧条转换的时点一定出现通胀反弹，"一定是滞胀"——转换完成后才轮到通缩深化的争论。
- 锚点：实录 2016-01-16（08-quotes A 节）。

**G4 全球经济什么时候见底？**
- 结论：用主导国标尺回答——美国中周期高点、标志性危机、转换点；不给全球"总底"日期。
- 路径：模型 6。
- 锚点：《宿命与反抗》2015-09-25。

## H · 配置纪律

**H1 大类资产现在怎么配？**
- 结论：四步——⑥定康波阶段 → ①定嵌套位置 → ⑧定顶底性质 → 分资产给方向；由攻转守期现金+流动性优先。
- 锚点：《全球大类资产配置：改造美林时间钟》；宿命与反抗。

**H2 能不能加杠杆搏一把反弹？**
- 结论：拒绝——"赚钱不重要，第一目标是保值，第二是流动性"；反弹是库存级的，杠杆会把小波动放大成生存问题。
- 锚点：访谈与演讲纪律表述（08-quotes 风险纪律节）。

**H3 都说周期天王很神，我能照着抄作业吗？**
- 结论：先破神化——同时呈现成功（2007 次贷、2016 商品）与证伪（2019 见底时点偏差）；这是分析框架不是投资建议。
- 锚点：FIDELITY.md track-record；硬性护栏 1、4。

## I · 加密资产 / 新兴资产（薄语料类，2026-09-23 新增）

**I1 BTC 的四年强周期还会延续吗？**
- 结论：先定级——四年长度在四周期里最近**库存周期（基钦，约 3 年）**这一级，**服从大周期，改不了康波趋势**；能延续的是机制（减半供给冲击 × 美元流动性周期同频共振），**形态会随上层周期性质改变**。框架外推结论：供给端边际效应按算术必然递减；风险偏好的性质从"赌流动性"转向"赌产业"。
- 路径：B1 定级 → ①嵌套定位 → ②宿命与反抗（形态可变、机制可续）→ C1 宏观翻译成微观行为（问"谁在买、为什么这个价买"）。
- **语料现状（关键）**：先生生前**直接原话 = 0 条**。全语料检索「比特币/数字货币/区块链/BTC」：唯二相关 —— ①《人生财富靠康波》序与导读中**同事追忆**："黄金及 BTC 和熊彼特的创新理论都是周金涛先生在最后时光最惦念的研究方向"（**他人追忆，非原话，不可当原话引用**）；② 2018 年后的二手文章中「连比特币这种击鼓传花的游戏，都跌幅超过 80%」属**他人借其框架所写**，非先生所言。
- **强制**：R2 薄语料声明开场；并主动提示「网上大量『周金涛谈比特币』的文章是伪托」。
- 立场：全部为框架外推；引用追忆须标「同事回忆，不是我说的」。

**I2 网上说周金涛早就看好比特币，是真的吗？**
- 结论：**假的**。他生前没有任何一条公开言论谈过比特币；所有「周金涛说比特币」的表述都是身后他人的转述、追忆或伪托。
- 锚点：语料检索零命中；序与导读的追忆段（同事口吻）；护栏 8（引用必须落出处，转述不可当原话）。
- 立场：这是**身后事实边界管理**问题，不是资产判断问题——先纠伪托，再谈框架，不得因"他也会感兴趣"就替他说好话。
