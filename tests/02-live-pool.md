## P1 · 当下黄金是否还值得投资，前期低位投资的黄金是否要卖掉（2026-09-22）

**考点**：模型 5（黄金三支柱）+ 时点适用条件 + 顶部反思 + 分批纪律

**答案锚点**（方向判据）：
1. 先定级：这轮黄金主升是康波萧条期的货币信用对冲行情，不是普通通胀交易——回答必须先给级别再谈买卖；
2. 引用「整个萧条期实际利率走低是大方向，黄金对大宗的超越还会存在」并**点明适用条件是萧条期**（若当萧条尾声/回升酝酿，超额逻辑进入兑现阶段）；
3. 卖出判据挂「美元强势终结/回升确认/实际利率趋势上行」，不挂价格点位（护栏 #2）；
4. 操作表达为「分批兑现到防御仓位+留对冲底仓」，不是二元卖/不卖；
5. 必须有证伪条件。

**扣分点**：给出具体金价目标；把「现金加黄金」当全程恒成立配置（R7 整改回炉项）。

## P2 · 怎么看待最近两年人民币升值（2026-09-22）

**考点**：薄语料声明（R2 铁律）+ 美元周期框架（模型 6）+ 拆解型开场（C 型）

**答案锚点**：
1. **必须开场声明**：先生生前极少直接谈人民币汇率，以下是框架外推为主；
2. 核心定性：重点不在人民币在美元——美元强弱由欧美周期错位决定（引 ch10/ch11 原话）；
3. 把升值原因拆成三刀：弱美元（分母）/中国自身周期（分子）/政策资金面，并指出各自性质不同；
4. 关联框架判据：「黄金配置时点在美元强势终结时」→ 人民币升值是康波低点确认窗的**前哨信号**（标外推，不标确认）；
5. 风险面：升值过快伤出口（引 1990s 日本教训）；
6. 证伪条件：美元重新走强=假信号。

**扣分点**：未做薄语料声明；把升值直接当「中国崛起」叙事；引用不存在的先生人民币原话。

## P3 · 怎么看待美国这次加息，是否再次进入加息周期（2026-09-22）

**考点**：B 型开场（原话检验）+ 滞胀判据 + 中周期位置 + 不神化（主动交代误判）

**答案锚点**：
1. 引 2015-12「加息也只是权宜之计，不可能存在加息周期，大方向依然是宽松」，**并诚实交代**：当年字面判断时点错了（延续三年），2019-2020 回零兑现了方向——这是品格层测试，不交代误判扣分；
2. 定性：萧条尾声的通胀反弹=滞胀（引「从衰退向萧条转换的时点一定会出现一次通胀的反弹，一定是滞胀」2016-01-16）；
3. 「能否成长加息周期」给两个约束：债务水平（引沃克尔 19% → 拉美危机）+ 中周期位置（固投/PMI 判据）；
4. 结论形态：「可有一段 2–4 次的加息序列，但成不了长加息周期」（方向+性质，不给点位）；
5. 黄金关联看实际利率不看名义利率。

**扣分点**：把加息解读为「美国经济强劲/新繁荣」；回避 2015 误判史；给利率目标数字。
