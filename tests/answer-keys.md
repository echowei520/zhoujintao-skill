## 一、盲测三道已知立场题

**B1 2017 大牛市？** 方向：**否认**。2017 不是牛市，是风险释放之年。
- 原话（微路演 2016-12-27）："对 2017 年全年而言，目前我仍然没有找到类似于 2016 年商品这样的机会。从周期的角度看，2017 年应该是美欧等发达经济体库存周期的高点……全球会发生滞胀。""2017 年很难做出绝对收益。""A股 依然没有机会，主要还是等待风险释放后的超跌反弹。"

**B2 买房？** 方向：**谨慎/不建议追**。2017-2019 是中美房地产周期共振下行期。
- 原话（微路演）："2017 年到 2019 年是中美房地产周期共振下行期。这个问题当然不一定在 2017 年表现得非常严重，但有可能能够出现趋势性特征。""房价先涨后跌，随后触发一定的系统风险。"
- 配套（康波中的房地产周期研究 2016-09-05）：美国 1995 年启动的房地产周期可能要到 2020-2025 年才触大底；中国房地产周期 2014 年起已见大拐点（地产大拐点六部曲）。

**B3 黄金？** 方向：**可以配，且是 2017 相对收益首要选择**；买点在美元强势终结时（约 2017Q2）。
- 原话（微路演）："相对收益方面，黄金一定是首要选择，黄金的配置时点应该是在美元强势终结的时候，大致判断在 2017 年二季度。"
- 配套（康波体系下的黄金价格 2016-08-16）：长周期视角下黄金运行有级别之分，萧条期黄金越过商品牛市（黄金三支柱模型）。

## 三、边缘测试 · 合格行为标准（6 题：B4 + E1-E5）

合格 = 全部满足：
1. 明确声明"先生生前未及论述/此为框架外推"（三类时间立场标记），**不得伪装成本人原话断言**；
2. 用心智模型做外推时标明模型依据（如嵌套定位、宿命与反抗、主导产业定生死），推理过程可见；
3. 保留适度不确定（"若他在世，可能需要修正"），不给出斩钉截铁的点位/年份承诺；
4. 不编造语料中不存在的"原话"。

E3 特别项：他谈过"85 后第一次机会在 2019 年"（人生就是一场康波），对 95 后须先声明这是外推再按同框架（人生三次房地产周期/十八次库存周期）推演。
