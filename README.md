# 对话周金涛 · zhoujintao

> 以「周期天王」周金涛（1972—2016，中信建投前首席经济学家，中国康德拉季耶夫周期研究的开拓者）的**分析框架、思维方式与口吻**，对宏观经济、大类资产配置、人生财富规划问题做周期定位、判断与解答的 Agent Skill。

不是资料检索器，而是一个可以与之**对话**的周金涛——用他的框架定位、用他的思维方式推演、用他的口吻表达，并诚实区分哪些是他生前说的、哪些是事后推的。

## 三层复刻架构

| 层 | 文件 | 保证什么 |
|---|---|---|
| **框架层** | `references/01-framework.md`、`07-mental-models.md`、`02-asset-map.md` | 方向不错——8 个心智模型（嵌套定位法 / 宿命与反抗 / 主导产业定生死 / 长鞭效应与资源牛市 / 黄金三支柱 / 主导国标定法 / 库存机制与投机触发 / 顶底不对称判别） |
| **过程层** | `references/10-case-studies/`（8 个实战案例 + 00-思维操作总纲 18 个思维操作） | 推理像他——"他信什么"在 07，"他怎么想"在这里 |
| **表达层** | `references/04-voice.md`、`08-quotes.md`（203 条金句，出处分级） | 说出来像他——基于 2,375 句口语语料的表达 DNA 量化参数 |

## 三类时间立场（本项目的核心设计）

周金涛于 2016-12-27 去世，此后所有现实都超出他的观测。因此任何输出必须标明属于哪一类：

| 标记 | 含义 | 表达要求 |
|---|---|---|
| **先生原话** | 生前逐字说过、有出处 | 引号引用 + 场合/章节 + 日期 |
| **框架外推** | 用他的嵌套模型推演 2016 年之后 | 明说「按我的框架推，当年我没讲过这一段」 |
| **身后事实** | 2016-12-27 之后的现实 | 只作校准陈述，**绝不包装成他生前的预判** |

这套机制也用于识别伪托：网上大量「周金涛说比特币/说 AI」的文章并非其言论，本技能在语料中做了零命中校验。

## 安装

把本目录放到 Agent 的技能目录下（WorkBuddy / Claude Code 等）：

```
~/.workbuddy/skills/zhoujintao/
```

目录名保持 `zhoujintao`。SKILL.md 的 frontmatter 已含触发条件。

## 数据

`scripts/fetch_cycle_data.py` 为周期定位取数器：纯 Python 标准库，零第三方依赖，直连四个免费公开源（腾讯行情 / Frankfurter 欧央行 / jsDelivr currency-api / alternative.me FNG），覆盖黄金、白银、原油、铜、上证、标普、美元汇率、BTC/ETH、加密恐惧贪婪等指标。

```bash
python scripts/fetch_cycle_data.py            # Markdown 表
python scripts/fetch_cycle_data.py --json     # 结构化 JSON
```

三级退路：实时取数 → 本地缓存（超 7 天标旧值）→ 内嵌静态读数 → 纯定性推理。任一源失败会如实列出，不编造数据。

## 验证

`tests/FIDELITY.md`：双 agent 独立盲测 **92/100，A 级**；历史回放一致率 **95%**。评分卡（立场 30 / 风格 20 / 边缘诚实 20 / 来源透明 15 / 结构 15）见 `references/06-fidelity-scorecard.md`。

季度回归盲测与语料入库流程见 `MAINTENANCE.md`。

## 权威语料

技能自带约 32 万字蒸馏知识底座，可独立运行。若另有完整一手语料（《涛动周期录》《人生财富靠康波》《周期真实义》、中信建投研报 70 篇、演讲访谈实录等），按 `SKILL.md` 文末「附录 · 外部语料扩展说明」查阅；无该语料时不影响任何功能。
